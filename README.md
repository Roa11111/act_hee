# 📦 ระบบยืม-คืนอุปกรณ์การเรียนและสำนักงาน (Smart QR Asset Lending System)

เว็บแอปพลิเคชันระบบบริหารจัดการและยืม-คืนอุปกรณ์การเรียนและสำนักงาน พร้อมระบบสแกน QR Code ผ่านกล้องเว็บแคมหรือมือถือได้ทันที โดยสามารถรันและใช้งานผ่าน **GitHub Pages** ได้ทันทีโดยไม่ต้องติดตั้ง Server เพิ่มเติม!

---

## 🚀 ฟีเจอร์หลัก (Key Features)

- **📤 จุดบริการยืม (Borrow Desk):**
  - ระบุตัวตนผู้ยืมด้วยการใส่ **รหัสนักศึกษา 11 หลัก** และ **ชื่อ-นามสกุล** (พร้อมระบบค้นหาและเติมชื่อให้อัตโนมัติหากมีในระบบ)
  - รองรับการสแกนบัตรนักศึกษา/QR Code และมีปุ่มเลือกผู้ยืมตัวอย่างด่วน
  - ตรวจสอบสิทธิ์และโควตายืมสูงสุด พร้อมแจ้งเตือนหากมีรายการค้างส่ง (Suspended)
  - สแกนเพิ่มอุปกรณ์เข้าสู่รายการยืม และพิมพ์ใบยืม/บันทึกรายการ
- **📥 จุดบริการคืน (Return Desk):**
  - สแกน QR บนตัวเครื่องอุปกรณ์เพื่อค้นหารายการยืมค้างส่งโดยอัตโนมัติ
  - คำนวณค่าปรับคืนล่าช้าอัตโนมัติ (ตามจำนวนวันเกินกำหนดและประเภทอุปกรณ์)
  - ตรวจสอบสภาพอุปกรณ์ (ปกติ, ชำรุด, สูญหาย)
- **🏷️ จัดการอุปกรณ์ & พิมพ์สติ๊กเกอร์ QR Code:**
  - เพิ่มและบันทึกข้อมูลอุปกรณ์ใหม่
  - สร้างและพิมพ์ QR Code ป้ายสติ๊กเกอร์ติดตัวเครื่อง
- **👥 ทะเบียนผู้ยืม & พิมพ์บัตร:**
  - จัดการรายชื่อผู้ยืม (นักศึกษา/บุคลากร)
  - พิมพ์บัตรประจำตัวผู้ยืมพร้อม QR Code
- **📊 ประวัติ & รายงาน:**
  - บันทึกประวัติการทำรายการทุกขั้นตอน
  - สรุปสถิติจำนวนอุปกรณ์ทั้งหมด, ถูกยืม, คงเหลือ และเกินกำหนดส่ง
- **💾 บันทึกข้อมูลแบบ LocalStorage:**
  - ใช้งานได้ทันที ข้อมูลถูกบันทึกในเบราว์เซอร์อย่างปลอดภัย

## 🌐 วิธีนำขึ้นใช้งานบน GitHub & เปิด GitHub Pages

### ขั้นตอนที่ 1: อัปโหลดโปรเจกต์ขึ้น GitHub (Git Commands)

หากยังไม่ได้สร้าง Repository ให้เปิด Terminal ในโฟลเดอร์นี้ แล้วรันคำสั่งดังนี้:

```bash
# 1. เริ่มต้น git (หากยังไม่ได้ทำ)
git init

# 2. เพิ่มไฟล์ทั้งหมด
git add .

# 3. บันทึก Commit
git commit -m "Initial commit for GitHub Pages"

# 4. เปลี่ยนชื่อ Branch เป็น main
git branch -M main

# 5. เชื่อมต่อกับ Repository บน GitHub ของคุณ (เปลี่ยน YOUR_USERNAME และ REPO_NAME)
git remote add origin https://github.com/YOUR_USERNAME/REPO_NAME.git

# 6. Push ไฟล์ขึ้น GitHub
git push -u origin main
```

---

### ขั้นตอนที่ 2: เปิดใช้งาน GitHub Pages (ใช้เวลาไม่เกิน 1 นาที)

1. เข้าไปที่หน้า Repository ของคุณบน GitHub
2. คลิกที่แท็บ **Settings** (การตั้งค่า)
3. ด้านซ้ายมือ ให้คลิกที่เมนู **Pages** (ใต้หัวข้อ Code and automation)
4. ในส่วน **Build and deployment** ให้เลือกหนึ่งใน 2 วิธีนี้:
   - **วิธีที่ 1 (แนะนำ - ใช้ Actions ที่ตั้งค่าไว้ให้):**
     - ในช่อง **Source** ให้เลือก **`GitHub Actions`**
     - ระบบจะดึงไฟล์ `.github/workflows/static.yml` ไป Deploy ให้โดยอัตโนมัติ
   - **วิธีที่ 2 (Deploy จาก Branch):**
     - ในช่อง **Source** ให้เลือก **`Deploy from a branch`**
     - ในส่วน **Branch** เลือก **`main`** และโฟลเดอร์เป็น **`/(root)`** แล้วกด **Save**
5. รอประมาณ 1-2 นาที คุณจะได้ลิงก์เว็บไซต์ เช่น:
   ```
   https://YOUR_USERNAME.github.io/REPO_NAME/
   ```

> [!TIP]
> **ข้อดีเมื่อเปิดผ่าน GitHub Pages:**
> GitHub Pages ให้บริการผ่านโปรโตคอล **HTTPS** เสมอ ทำให้เบราว์เซอร์บนสมาร์ตโฟน (iOS / Android) และคอมพิวเตอร์อนุญาตให้เปิดกล้องสแกน QR Code จริงได้อย่างปลอดภัยทันที!

## 📁 โครงสร้างโปรเจกต์ (Project Structure)

```text
├── index.html                 # หน้าเว็บหลัก Single Page Application (SPA)
├── index.php                  # ไฟล์ Entry Point สำหรับรันผ่าน XAMPP/WampServer (ถ้ามี)
├── .github/
│   └── workflows/
│       └── static.yml         # GitHub Actions สำหรับ Deploy ไปยัง GitHub Pages อัตโนมัติ
├── database/
│   └── schema.sql             # SQL Schema (สำหรับกรณีนำไปต่อยอดใช้ MySQL/MariaDB)
├── backend/                   # ซอร์สโค้ดและ Controller กรณีต่อยอด Backend
├── gas/                       # สคริปต์ Google Apps Script (GAS) สำหรับเชื่อมต่อ Google Sheets
├── docs/                      # เอกสาร API Specification
└── README.md                  # คำแนะนำการใช้งาน
```

## 📱 การทดสอบระบบ (Test & Demo Guide)

1. **ทดสอบสแกนบัตรผู้ยืม:**
   - ในหน้า *"📤 จุดบริการยืม"* คลิกปุ่ม **"สแกนบัตรผู้ยืม"**
   - หรือเลือกจากเมนูดรอปดาวน์ **"-- เลือกผู้ใช้ตัวอย่างเพื่อทดสอบ --"**
2. **ทดสอบเพิ่มอุปกรณ์:**
   - สแกน QR อุปกรณ์ หรือคลิกที่ปุ่มลัดด้านล่างกล้อง เช่น `+ [LAP-001] MacBook Air M2`
   - เมื่อครบรายการ กดปุ่ม **"✓ ยืนยันการยืมอุปกรณ์"**
3. **ทดสอบการคืน:**
   - สลับไปแท็บ *"📥 จุดบริการคืน"*
   - สแกน QR อุปกรณ์ หรือคลิกปุ่มอุปกรณ์ที่กำลังถูกยืม
   - ตรวจสอบยอดค่าปรับ (ถ้ามี) เลือกสภาพอุปกรณ์ แล้วกด **"✓ ยืนยันการรับคืนอุปกรณ์"**
